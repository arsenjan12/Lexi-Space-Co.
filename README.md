# LEXI Space

[![License: Apache 2.0](https://img.shields.io/badge/license-Apache%202.0-c49d47.svg)](LICENSE)
[![Сайт](https://img.shields.io/badge/сайт-lexi--space.netlify.app-1f1d1a.svg)](https://lexi-space.netlify.app)

Ситуационный центр LEXI: звёзды, планеты, галактики и спутники в реальном времени, формулы и алгоритмы защиты космической инфраструктуры и ассистент LexiAI, который работает прямо в браузере. Открытый проект — код можно смотреть, проверять и предлагать правки.

> **English.** LEXI Space is an open-source situation center for space infrastructure: real-time satellites (CelesTrak + SGP4), the Solar System and the sky above you, 31 formulas from three security modules (spacecraft cybersecurity, GNSS anti-jamming and integrity, post-quantum cryptography) with live calculators, eight protection indicators computed from real data, and LexiAI — a Qwen2.5-1.5B model fine-tuned on the LEXI knowledge base that runs fully in the browser. Licensed under Apache 2.0.

Что внутри:

- **Орбита** — Земля (текстуры портала), реальные спутники по элементам CelesTrak и модели SGP4, Луна, звёздное небо.
- **Солнечная система** — планеты на своих настоящих местах сейчас (astronomy-engine), орбиты, кольца Сатурна.
- **Небо** — что видно над вами прямо сейчас: 5070 звёзд, 88 созвездий, 115 галактик, туманностей и скоплений, планеты, горизонт.
- У каждого объекта есть карточка с живыми данными (положение, азимут, восход/заход, доплер, следующий пролёт…) и 3D-моделью: планеты, звёзды по температуре, галактики по типу, туманности, скопления, спутники, астероиды.
- **Модули** — три модуля портала, разложенные по связям: угроза → чем обнаруживается → чем закрывается → какой формулой считается. 31 формула с калькуляторами.
- **Состояние защиты** — 8 живых показателей, которые реально вычисляются (подробности ниже).
- **LexiAI** — ассистент: отвечает по базе знаний, считает формулы, знает, где сейчас МКС. Поверх — своя нейросеть, дообученная на базе LEXI на RTX 3060, работает прямо в браузере.

## Запуск у себя

Нужен Node.js 20+.

```bash
npm install
npm run serve
```

Открыть http://localhost:8888. Локальный сервер отдаёт сайт с теми же заголовками, что Netlify, и запускает функции `/api/*`, так что Netlify CLI не нужен.

## Публикация на Netlify

1. Netlify → Add new site → **Import from Git** (папку загрузить на GitHub) или из этой папки командой `npx netlify-cli deploy --prod`. Настройки уже в `netlify.toml`: публикуется `site`, функции — `netlify/functions`. Простое перетаскивание папки в Netlify не подойдёт: так не публикуются функции `/api/*`.
2. Имя сайта — **lexi-space**. Тогда адрес будет `https://lexi-space.netlify.app/`, и на него уже ведёт портал. Если имя занято, поменяйте `spaceUrl` в `Lexi web/index.html` (строка с `spaceUrl:` в блоке `CONFIG`).
3. Site configuration → Environment variables:
   - `LEXI_PQ_SEED` — значение из файла `.env` (создаётся командой `npm run keys`). Это секретный ключ подписи — файл `.env` никуда не выкладывать.
   - `NASA_API_KEY` — ключ с https://api.nasa.gov (бесплатно). Без него работает общий `DEMO_KEY`, но с жёстким лимитом.
4. Чтобы «← LEXI» вёл на портал по прямой ссылке, впишите адрес портала в `site/js/config.js` → `portalUrl`. Пока пусто, ссылка ведёт туда, откуда человек пришёл.

### База данных

SQLite, работает прямо в браузере (sql.js). Схема — `db/schema.sql`, там же комментарии к каждой таблице.

- `01_logic.sql` — цели, угрозы, контрмеры, формулы с параметрами, живые показатели и **связи** между всем этим (таблица `links`). Это и есть «что с чем взаимодействует».
- `02_solar_sats.sql` — планеты, группы спутников, известные аппараты.
- `03_module_texts.sql` — полные тексты модулей **с портала** (генерируется).
- `10_sky.sql` — звёзды, созвездия, галактики (генерируется из каталогов).

Если поменялись тексты модулей на портале:

```bash
npm run import   # заново читает Lexi web/lexi-translations.js
npm run db       # собирает site/data/lexi.sqlite
```

### Живые показатели защиты

Раньше в `server.py` был блок `SECURITY_CONFIG` с вечными `True` и `PQ_TOKEN_XXXXXX`. Он убран. Теперь каждый показатель считается из настоящих данных, а если данных нет, так и написано:

| Показатель | Как считается |
|---|---|
| Подпись данных ML-DSA-65 | сервер подписывает орбиты, астероиды и Kp; браузер проверяет подпись открытым ключом |
| Гибридный ключ X25519 + ML-KEM-768 | при загрузке браузер проводит настоящее согласование ключа и сверяет, что ключи совпали |
| Целостность орбитальных элементов | контрольные суммы строк TLE и возраст элементов |
| МКС и Южно-Атлантическая аномалия | положение МКС по SGP4 относительно области повышенной радиации |
| Геометрия GPS над вами | видимые спутники GPS и PDOP для вашей точки |
| Доступность RAIM | хватает ли спутников, чтобы заметить (5) и исключить (6) сбойный |
| Фильтр Калмана по геолокации | невязки фильтра и тест χ² по точкам вашего устройства |
| Космическая погода | индекс Kp от NOAA |

## LexiAI

Два слоя:

1. **База знаний.** Поиск по 1600 фрагментам из базы (модули разрезаны на отдельные пункты, есть словарь разговорных синонимов: «навигатор врёт» → спуфинг), живые данные объектов и калькуляторы. Работает сразу, без загрузки.
2. **Нейросеть.** Qwen2.5-1.5B-Instruct, дообученная методом QLoRA на RTX 3060 Laptop (6 ГБ). Работает прямо в браузере через llama.cpp → WebAssembly. Файл ≈ 1,1 ГБ (Q5_K_M, 13 кусков по 95 МБ) скачивается один раз по кнопке «Включить нейросеть». Если поиск ничего не нашёл, нейросеть не вызывается — LexiAI честно отвечает «не нашёл», а не сочиняет.

### Чему обучена

Выборка собирается из той же базы, что у сайта (`ai/build_dataset.py`), ≈ 2400 примеров на русском и английском:

- угрозы: что это, как обнаружить, как защититься, насколько опасна, и бытовые вопросы («почему навигатор врёт возле аэропорта», «может ли хакер развернуть спутник»);
- контрмеры и формулы, а также ≈ 300 настоящих расчётов теми же калькуляторами, что на сайте;
- модули, цели, живые показатели, связи между модулями;
- планеты, звёзды, галактики, спутники, в том числе с живыми данными («где сейчас МКС»);
- честные отказы на вопросы не по теме.

Контекст в каждом примере собирается тем же поиском, что на сайте (`ai/retrieval.py`), — модель учится на том, что реально увидит.

### Результат

| | Ключевые факты на 60 отложенных вопросах |
|---|---|
| Исходная Qwen2.5-1.5B | 39 % |
| **LexiAI (дообученная)** | **77 %** |

Как к этому пришли: первая версия (2 эпохи, lr 2e-4) выучила шаблоны и отказывалась отвечать, если поиск приносил не точную карточку, а раздел модуля. Вторая (контекст из поиска сайта, бытовые вопросы, 1 эпоха, lr 1e-4) отвечала лучше, но на пустой контекст начинала сочинять. В третьей разделы модулей разрезаны на пункты, добавлены отказы и защита на сайте. Ответы всех версий на одни и те же вопросы — в `docs/lexiai-eval/`.

Честно об ограничениях: это маленькая модель. Иногда она добавляет лишнюю деталь или вставляет английское слово в русский ответ. Числа и названия надёжнее всего, когда они есть в контексте, — поэтому живые данные и расчёты сайт подставляет сам.

### Как обучить заново

Windows, видеокарта NVIDIA от 6 ГБ:

```bash
python -m venv ai/.venv
ai\.venv\Scripts\pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu124
ai\.venv\Scripts\pip install -r ai/requirements.txt
python ai/build_dataset.py                        # выборка из базы → ai/out/train.jsonl
ai\.venv\Scripts\python ai/train.py               # QLoRA, ≈ 55 минут на RTX 3060 Laptop
ai\.venv\Scripts\python ai/smoke_test.py          # вопросы, которых нет в выборке
ai\.venv\Scripts\python ai/evaluate.py            # доля ключевых фактов
ai\.venv\Scripts\python ai/export_gguf.py         # GGUF Q5_K_M → site/models + site/data/ai-model.json
```

Базовую модель положить в `ai/cache/Qwen2.5-1.5B-Instruct` (файлы с https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct). Если видеокарта на 6 ГБ начинает выгружать память в ОЗУ (обучение резко замедляется), закройте браузеры и прочие программы, использующие видеокарту, и подключите ноутбук к зарядке.

### Где лежит модель

Файлы модели (13 кусков по 95 МБ) опубликованы в [GitHub Releases](https://github.com/f4ckpy/Lexi-Space-Co./releases) этого репозитория, в самом git их нет. Браузер не может скачивать их с GitHub напрямую (GitHub не отдаёт заголовок CORS), поэтому Netlify при сборке забирает их из релиза командой `node scripts/fetch-model.mjs` и раздаёт вместе с сайтом. Список файлов и тег релиза — в `site/data/ai-model.json`.

Новая версия модели: `ai/export_gguf.py` → новый релиз с файлами из `site/models` → обновить поле `release` в `site/data/ai-model.json`.

Формат запроса и поиск описаны дважды — в `ai/prompt.py` + `ai/retrieval.py` и в `site/js/lexiai.js` + `site/js/db.js`. Их нужно менять синхронно.

## Что взято из первой версии сервера (проект Lexi)

- Формулы `server.py`: орбитальная скорость, первая космическая, Доплер, фильтр Калмана для GNSS — они в базе и в калькуляторах (у формул пометка `origin = 'gosha'`, по имени автора первой версии).
- Запрос к NASA NeoWs — теперь функция `/api/neo`.
- Тексты научных модулей — совпадают с порталом.

Что исправлено:

- телеметрия Starlink генерировалась случайными числами (`random.uniform`) — теперь настоящие орбиты из CelesTrak и SGP4;
- в запрос к NASA вместо ключа подставлялся адрес API, а дата `2026-10-16` была зашита в код;
- `calculate_orbital_velocity` умножала результат на 1000 и называла его км/с;
- `calculate_gravitational_velocity` брала расстояние в а.е. для спутника Земли;
- `update()` в фильтре Калмана возвращала кортеж, а вызывающий код распаковывал его в две переменные;
- `index.html` подключал `styles.css`, а файл назывался `style.css`;
- блок `SECURITY_CONFIG` — см. выше.
