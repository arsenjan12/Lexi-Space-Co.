# Как участвовать

Спасибо, что хотите помочь LEXI Space.

## Запустить у себя

```bash
npm install
npm run serve        # http://localhost:8888
```

Для подписи данных локально создайте свой ключ: `npm run keys` (он попадёт в `.env`, который не коммитится).

## Что можно предложить

- исправления в расчётах и формулах — с источником (статья, стандарт);
- новые объекты, группы спутников, синонимы для поиска (`db/seed/*.sql`) — после правки `npm run db`;
- улучшения интерфейса и переводов (`site/js/i18n.js`);
- примеры для обучения LexiAI (`ai/build_dataset.py`).

## Правила

- Код пишем так же, как написан остальной: понятные имена, короткие комментарии по-русски там, где нужно объяснить «почему».
- Формат запроса к модели и поиск описаны дважды — `ai/prompt.py` + `ai/retrieval.py` и `site/js/lexiai.js` + `site/js/db.js`. Меняйте синхронно.
- Никаких секретов, ключей и личных данных в коммитах.
- Одна правка — один pull request с понятным описанием, что и зачем.

Отправляя правку, вы соглашаетесь, что она распространяется по лицензии проекта (Apache 2.0).
