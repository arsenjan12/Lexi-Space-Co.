# LEXI Messenger

Защищённый мессенджер для астрономов и космической отрасли. Дизайн по эскизу Арсения, стиль LEXI Space. Работает с сервером Георгия (`server.py`) без изменений в нём.

## Где лежит

LEXI Messenger — отдельный сайт (https://lexi-messenger.netlify.app), код — в папке `messenger/` репозитория LEXI Space.

* `messenger/site/` — веб-приложение (`index.html`, `css/`, `js/`, `data/`).
* `messenger/scripts/build.mjs` — сборка: копирует в `site/space/` общие файлы LEXI Space (библиотеки, шрифты, текстуры, 3D-модели, базу знаний LexiAI). Во время работы мессенджер от сайта LEXI Space не зависит.
* `messenger/netlify.toml` — настройки отдельного сайта на Netlify (Base directory = `messenger`).
* `messenger/sql/`, `REVIEW.md`, этот файл — документы, в публикацию не попадают.

**Нейросеть** LexiAI мессенджер берёт с сервера LEXI Space (`https://lexi-space.netlify.app/models/…`, описание — `data/ai-model.json` там же), второй копии в 1,1 ГБ нет. В браузере у мессенджера свой кэш (браузер разделяет хранилища разных сайтов): модель скачивается один раз и потом запускается из кэша.

## Запуск

```bash
cd messenger
node scripts/build.mjs                  # один раз и после обновления файлов LEXI Space
npx serve site                          # или любой статический сервер → http://localhost:3000
```

* Кнопка **«Войти»** подключается к серверу из настроек (Связь → адрес). Если адреса нет или сервер не ответил за 4,5 с, открывается демо.
* Маленькая кнопка **«демо»** сразу открывает демо: ретранслятор и десять участников работают во вкладке, шифрование настоящее.
* Сервер: `uvicorn server:app --port 8000`, адрес `ws://localhost:8000/ws`.

WebCrypto работает только по `https://` или с `localhost`.

## Как устроено по эскизу

* **Загрузка**: звёздное небо, логотип LEXI рассыпается на точки и собирается в сетевой глобус между словами «Lexi» и «Messenger». Нажатие пропускает.
* **Первый вход**: HELLO WORLD! над Землёй со спутниками (Three.js на мощных устройствах, картинка на слабых) → планшет интересов → профиль на панели Starlink (фото, имя, позывной, роль, организация) → «Добро пожаловать в Lexi Messenger». Повторный вход: загрузка → сразу чаты.
* **Шапка-капсула**: # Ветки · Каналы · Чаты · All · Unread · LexiAI · Edit, поиск, колокольчик, профиль.
* **Кружки слева** — вперемешку по активности: пространства (скруглённые квадраты), чаты, люди в сети.
* **Список**: `#` — канал (пишут только админы), пузырь — группа, человечек — личный чат. Сверху «Зал славы».
* **Чат** — стеклянная карточка с крестиком. Пузыри, свои справа. У сообщения три действия: реакция, ответ в ветке, переслать. Замок в шапке — про шифрование и сверку ключей; ⓘ — описание, участники (✓ у проверенных учёных), медиа.
* **TOOLS** внизу справа раскрывает колонку: астропрогноз, планирование, карта светового загрязнения, алерты (расчёт событий неба + Kp NOAA), координаты, формулы, Lexi Space. Инструмент открывается окном поверх чата, окно можно таскать.
* **LexiAI** — вкладка и `@lexi` в любом чате. Сразу работает база знаний LEXI Space; нейросеть (1,1 ГБ) включается кнопкой, кеш общий с сайтом LEXI Space.
* **Фон**: случайная планета или экзопланета (сменить — подпись внизу или настройки), при открытом чате затемняется. В чатах тусклые созвездия, в поиске и LexiAI — глубокий космос.
* **Жидкое стекло** везде: размытие и преломление фона, блик следует за курсором.
* **Темы**: тёмная золотая, тёмная циан, светлая, красная телескопная.
* **Модерация**: премодерация в группах, метка «ИИ» (ставит автор через «+»), подсказка детектора ИИ видна только админам, значок учёного ставит сотрудник LEXI вручную.
* **Зал славы**: сообщения, на которые отреагировали трое и больше.
* **Ввод**: FITS и картинки (перетаскиванием или через «+»), рисунок, формулы LaTeX, Markdown, ссылки SIMBAD / NED / arXiv / NASA.
* **Телефон**: полная версия — чат на весь экран, окна инструментов снизу, действия над сообщением по нажатию.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html`, `css/messenger.css` | Разметка и стили |
| `js/app.js` | Интерфейс |
| `js/boot.js` | Анимация загрузки |
| `js/scene3d.js` | 3D: планеты за интерфейсом, орбита при регистрации |
| `js/space-bg.js` | 2D-фоны для слабых устройств, созвездия, глубокий космос |
| `js/lexi-e2e.js` | Криптография: ML-KEM-768, HKDF, AES-256-GCM, ключи каналов |
| `js/lexi-client.js` | Доработанный клиент Георгия |
| `js/demo-relay.js`, `js/demo-bots.js` | Сервер во вкладке и участники демо |
| `js/lexiai.js` | LexiAI: база знаний (копия из LEXI Space) и нейросеть с сервера LEXI Space; поиск и запрос к модели синхронны с `site/js/lexiai.js` и `db.js` |
| `js/ai-detect.js` | Подсказка «похоже на ИИ» для модераторов |
| `js/render.js`, `js/fits.js` | Markdown, LaTeX, каталоги; чтение и отрисовка FITS |
| `js/tools.js`, `js/astro.js` | TOOLS и астрономические расчёты |
| `sql/schema.sql` | PostgreSQL: только шифротекст, Argon2id, RLS, каналы/группы/личка, значок учёного |
| `sql/security_tests.sql` | 29 проверок безопасности схемы |
| `REVIEW.md` | Разбор кода и правки сервера для Георгия |
